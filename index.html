Methodology: Singh (IMF) defines the collateral multiplier as pledged-collateral / primary-source collateral. This proxy uses daily US Treasury repo volumes (SOFR, TGCR, BGCR from the NY Fed) as the numerator and Treasury free-float (debt held by public minus Fed SOMA holdings) as the denominator. Higher velocity implies more re-pledging per dollar of available collateral.

Caveats: Captures Treasury repo only — misses MBS repo, securities lending, and prime-brokerage rehypothecation. The denominator uses total public float rather than primary-dealer inventories, so the absolute level is not directly comparable to Singh's quarterly figures. This is a direction-of-travel indicator.

Sources: NY Fed Reference Rates API (SOFR/TGCR/BGCR volumes) · Treasury Fiscal Data API (debt held by public) · FRED TREAST (Fed SOMA Treasury holdings) · Updated daily via GitHub Actions.
